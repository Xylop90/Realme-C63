## How to Get Listed / Wie man gelistet wird

Deine Beiträge werden automatisch anerkannt, wenn du:

Your contributions are automatically recognized when you:

1. **Code beiträgst** / Submit code
   - Pull Requests die gemerged werden
   - Pull requests that get merged

2. **Dokumentation verbesserst** / Improve documentation
   - Tippfehler korrigierst / Fix typos
   - Guides verbesserst / Improve guides
   - Übersetzungen hinzufügst / Add translations

3. **Bugs meldest** / Report bugs
   - Wichtige Bugs findest / Find important bugs
   - Detaillierte Reports erstellst / Create detailed reports

4. **Der Community hilfst** / Help the community
   - Fragen beantwortest / Answer questions
   - Anderen Nutzern hilfst / Help other users

### Recognition Levels / Anerkennungsstufen

#### 🥇 Gold Contributors
- Signifikante Code-Beiträge / Significant code contributions
- Mehrere wichtige Features / Multiple major features
- Langfristige Projekt-Beteiligung / Long-term project involvement

#### 🥈 Silver Contributors
- Mehrere erfolgreiche PRs / Multiple successful PRs
- Wichtige Bug-Fixes / Important bug fixes
- Dokumentationsverbesserungen / Documentation improvements

#### 🥉 Bronze Contributors
- Erste Beiträge / First contributions
- Bug Reports / Bug reports
- Community-Hilfe / Community help
