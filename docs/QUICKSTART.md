# Quick Start Guide - Realme C63 Installation

**⚡ Schnellanleitung für eilige Nutzer**

---

## 1️⃣ Vorbereitung (5 Minuten)

### PC vorbereiten
```
✅ Windows 11 oder Windows 10
✅ Mindestens 10 GB freier Speicherplatz
✅ Stabile Internet-Verbindung
✅ Administrator-Rechte
```

### Gerät vorbereiten
```
✅ Akku mindestens 50% geladen
✅ Wichtige Daten gesichert (werden gelöscht!)
✅ Hochwertiges USB-Kabel bereit
```

---

## 2️⃣ Installation (1 Klick)

### Schritt 1: Repository laden
```bash
git clone https://github.com/Xylop90/Realme-C63.git
```

Oder ZIP herunterladen und entpacken

### Schritt 2: Installation starten

**Doppelklick auf:**
```
install.cmd
```

**Fertig!** 🎉

---

## 3️⃣ Was passiert automatisch?

```
[1/8] Verzeichnisse werden erstellt...       ✅
[2/8] Konfiguration wird generiert...        ✅
[3/8] System wird vorbereitet...             ✅
[4/8] Tools werden heruntergeladen...        ✅
[5/8] Treiber werden installiert...          ✅
[6/8] Firmware wird vorbereitet...           ⏸️
[7/8] SPD Flash Tool wird eingerichtet...    ✅
[8/8] Dokumentation wird erstellt...         ✅
```

---

## 4️⃣ Firmware (einmalig)

**Falls noch keine Firmware vorhanden:**

1. **Download von:**
   - https://www.getdroidtips.com/realme-c63-stock-rom/

2. **Speichern in:**
   ```
   Realme-C63/firmware/
   ```

3. **Script erneut ausführen**

---

## 5️⃣ Flash-Prozess (10 Minuten)

### SPD Flash Tool öffnet sich automatisch

**Manuelle Schritte:**

```
1. Klicke "Load Packet"
2. Wähle Firmware-Datei (.pac)
3. Gerät ausschalten
4. Download-Modus: Power + Vol Up/Down
5. USB-Kabel anschließen
6. Klicke "Start"
7. Warten auf "Passed" (5-10 Min)
8. Fertig! ✅
```

---

## 🎯 Zusammenfassung

```
1. install.cmd doppelklicken          → 1 Minute
2. Firmware herunterladen (optional)   → 5 Minuten
3. Firmware flashen                    → 10 Minuten
─────────────────────────────────────────────────
GESAMT:                                 ~15 Minuten
```
