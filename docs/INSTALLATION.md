# Installationsanleitung - Realme C63 (RMX3939)

## Übersicht

Diese Anleitung führt Sie durch die vollautomatische Installation des Realme C63 Flash-Systems.

## Voraussetzungen

### Hardware
- **Realme C63 (RMX3939)** Smartphone
- **USB-Kabel** (Original oder hochwertig)
- **Windows PC** (Windows 10 oder 11, 64-bit)
- **5 GB freier Speicherplatz**

### Software
- Windows 10/11 (Build 19041 oder neuer)
- PowerShell 5.1+ (in Windows enthalten)
- Administrator-Rechte auf dem PC
- Internetverbindung (mindestens 2 Mbit/s)

## Schritt-für-Schritt Installation

### Schritt 1: Repository herunterladen

**Option A: Mit Git**
```powershell
git clone https://github.com/Xylop90/Realme-C63.git
cd Realme-C63
```

**Option B: ZIP-Download**
1. Besuchen Sie https://github.com/Xylop90/Realme-C63
2. Klicken Sie auf "Code" → "Download ZIP"
3. Entpacken Sie die ZIP-Datei
4. Öffnen Sie den entpackten Ordner

### Schritt 2: Installer starten

1. Doppelklick auf `INSTALL.bat`
2. Bei UAC-Aufforderung auf "Ja" klicken

### Schritt 3: Automatischer Ablauf

Der Installer führt automatisch durch den Installations-Prozess.

Für vollständige Details siehe [README.md](../README.md)
