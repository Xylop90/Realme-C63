- **Gerät:** Realme C63
- **Android Version:** Android 14 (Realme UI 5.0)
- **TWRP Recovery:** v3.7.0 oder höher
- **ADB & Fastboot** auf dem PC installiert
- **USB-Debugging** aktiviert
- **Bootloader entsperrt** (Siehe Guide unten)
