# Realme C63 (RMX3939) - Device Specifications

## Basic Information
- **Device Name:** Realme C63
- **Model Number:** RMX3939
- **Manufacturer:** Realme
- **Release Date:** 2024
- **Current Status:** Active

## Display
- **Size:** 6.74 inches
- **Type:** IPS LCD
- **Resolution:** 720 x 1600 pixels (~260 ppi)
- **Refresh Rate:** 90Hz
- **Protection:** Not specified

## Performance
- **Chipset:** MediaTek Helio G85 (12nm)
- **CPU:** Octa-core (2x2.0 GHz Cortex-A75 & 6x1.8 GHz Cortex-A55)
- **GPU:** Mali-G52 MC2

## Memory
- **RAM Options:** 4GB, 6GB, 8GB
- **Storage Options:** 64GB, 128GB, 256GB
- **Expandable:** microSDXC (dedicated slot)

## Software
- **OS:** Android 12
- **UI:** Realme UI 3.0
- **Upgradable:** Check official sources

## Camera
### Main Camera
- **Primary:** 50 MP, f/1.8, (wide)
- **Secondary:** 2 MP (depth or macro)
- **Features:** LED flash, HDR, panorama
- **Video:** 1080p@30fps

### Selfie Camera
- **Resolution:** 8 MP, f/2.0
- **Video:** 1080p@30fps

## Battery
- **Capacity:** 5000 mAh (non-removable)
- **Charging:** 45W wired fast charging
- **Battery Life:** Up to 2 days normal usage

## Connectivity
- **Network:** 2G, 3G, 4G LTE
- **Wi-Fi:** 802.11 a/b/g/n/ac, dual-band
- **Bluetooth:** 5.0
- **GPS:** Yes, with A-GPS, GLONASS, GALILEO, BDS
- **USB:** USB Type-C 2.0
- **NFC:** No
- **Radio:** FM radio

## Sensors
- Fingerprint (side-mounted)
- Accelerometer
- Proximity
- Compass

## Build
- **Dimensions:** 165.7 x 76.1 x 7.9 mm
- **Weight:** ~189g
- **Colors:** Leather Blue, Leather Green, Jade Green

## Audio
- **Loudspeaker:** Yes, with stereo speakers
- **3.5mm jack:** Yes

## Bootloader & Root
- **Bootloader:** MediaTek, can be unlocked
- **Root Support:** Yes, via Magisk
- **Custom Recovery:** TWRP available
- **Custom ROMs:** Limited availability

## Partitions
- **System Partition:** Dynamic partition (dm-0)
- **Vendor Partition:** Dynamic partition (dm-1)
- **Boot:** /dev/block/platform/bootdevice/by-name/boot
- **Recovery:** /dev/block/platform/bootdevice/by-name/recovery
- **Userdata:** /dev/block/platform/bootdevice/by-name/userdata

## Known Issues
1. Limited custom ROM support (new device)
2. MediaTek chipset (harder to unlock/modify)
3. TWRP support may be limited
4. Some banking apps may not work after root

## Notes for Developers
- Use MediaTek SP Flash Tool for low-level operations
- Backup all partitions before modifications
- IMEI backup is critical
- Some partitions are write-protected
- SELinux mode: Enforcing (can be set to Permissive)

## Warranty Warning
⚠️ **Unlocking bootloader and rooting will void warranty!**
- Always backup your data
- Understand the risks
- Follow official guides
- Keep original firmware for restore
