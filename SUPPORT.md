## 🐛 Reporting Bugs / Fehler melden

Wenn du einen Bug gefunden hast:

If you've found a bug:

1. **Suche zuerst** in [GitHub Issues](https://github.com/Xylop90/Realme-C63/issues) nach ähnlichen Problemen
   
   **Search first** in [GitHub Issues](https://github.com/Xylop90/Realme-C63/issues) for similar problems

2. **Erstelle ein neues Issue** mit unserem Bug Report Template
   
   **Create a new issue** using our Bug Report template

3. **Inkludiere:**
   - Klare Beschreibung des Problems / Clear problem description
   - Schritte zur Reproduktion / Steps to reproduce
   - Erwartetes vs. tatsächliches Verhalten / Expected vs. actual behavior
   - Screenshots / Logs (falls relevant / if applicable)
   - Geräteinfo (ROM-Version, Android-Version, etc.) / Device info

**[→ Bug Report erstellen / Create Bug Report](https://github.com/Xylop90/Realme-C63/issues/new?template=bug_report.md)**

## 📋 Before Asking for Help / Vor der Hilfe-Anfrage

Überprüfe diese Checklist:

Check this checklist:

- [ ] Hast du die relevante Dokumentation gelesen? / Have you read the relevant documentation?
- [ ] Hast du nach ähnlichen Issues gesucht? / Have you searched for similar issues?
- [ ] Verwendest du die neueste ROM-Version? / Are you using the latest ROM version?
- [ ] Hast du einen sauberen Flash versucht? / Have you tried a clean flash?
- [ ] Hast du Logs gesammelt (falls zutreffend)? / Have you collected logs (if applicable)?
- [ ] Ist dein Bootloader entsperrt? / Is your bootloader unlocked?
- [ ] Ist TWRP korrekt installiert? / Is TWRP correctly installed?
